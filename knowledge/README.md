# LifeLingo Knowledge Base v001

This is curated retrieval knowledge, not model-training data. Every item has a stable ID, CEFR learning level, reusable skill ID, goal/scenario metadata, English content, Persian support, examples, quality label and version.

The runtime loads only candidate files for the learner level/domain and ranks individual items. Retrieved IDs are retained with AI turns for evaluation. Translation labels never act as internal IDs.

Quality labels follow: `LIFELINGO_VERIFIED`, `SYSTEM_GROUND_TRUTH`, `HUMAN_VERIFIED`, `UNVERIFIED_USER_CONTENT`, `MODEL_GENERATED`, and `SYNTHETIC`.
